# I Confessed First

One-line excuse from a home Wi-Fi router for dropping the connection at the climax of a movie.

Entry: "The villain was about to confess, so I confessed first: I unplugged myself."

The joke: the router steals the villain's climax — it confesses first, by unplugging itself.

Run `node main.ts` — it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

Gate: one line, UTF-8, 1–200 characters (this entry: 76 chars). The program validates the length before writing and fails loudly if the gate is missed.
